# promo

Промо-макеты GusevMade: шесть вариантов оформления сайта «Дом мёда» для WordPress.

- `dom-meda/` фирменные цвета
- `dom-meda-bold/` с анимацией
- `dom-meda-craft/` крафт
- `dom-meda-minimal/` минимализм
- `dom-meda-natural/` натуральные дары
- `dom-meda-altai/` дары Горного Алтая
- `dom-meda-photo/` фото-концепт

Главная страница показывает макеты в режимах «Компьютер» и «Телефон». Это демо дизайна, не работающий WordPress.
